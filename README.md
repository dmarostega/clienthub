# ClientHub

SaaS para portal do cliente, acompanhamento de projetos, etapas, tarefas, aprovações e entregas para freelancers, desenvolvedores, designers, pequenas agências e prestadores digitais.

## Stack

- Laravel 13
- Vue.js 3
- TypeScript
- MySQL
- Tailwind CSS
- Vite
- Inertia.js

## Objetivo

Permitir que profissionais e pequenas equipes organizem projetos e disponibilizem uma área simples para o cliente acompanhar etapas, aprovar entregas e visualizar o andamento.

## Funcionalidades previstas

- Autenticação
- Dashboard
- CRUD de clientes
- CRUD de projetos
- Etapas do projeto
- Tarefas
- Comentários
- Upload de arquivos
- Aprovação de etapas
- Portal/link de acompanhamento para cliente
- Painel admin
- CRUD de planos
- Configurações globais
- SEO
- robots.txt
- sitemap.xml
